# Deployment Guide

This document describes how to deploy the AI-Process Digital Twin dashboard. 

The deployment strategy for this project is strictly **Streamlit Community Cloud** (or standard Streamlit execution from a GitHub repository). Docker is NOT required and should not be used.

## Prerequisites
- Python 3.13 (for local execution)
- Git (for repository cloning)

## Local Deployment

To run the application locally in a clean environment:

1. Clone the repository and navigate to the root directory.
2. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. Install dependencies. The project separates runtime dependencies from development/simulation dependencies:
   ```bash
   pip install -r requirements.txt      # For dashboard runtime only
   pip install -r requirements-dev.txt  # For simulation and testing
   ```
4. Run the Streamlit application:
   ```bash
   streamlit run app/streamlit_app.py
   ```
5. The application will be accessible at `http://localhost:8501`.

## Streamlit Community Cloud

The project is natively compatible with Streamlit Community Cloud. Because the dashboard relies exclusively on Git-tracked pre-computed data (`data/dashboard/*.csv`) and standard Python dependencies, no complex CI/CD, external backend service, or database provisioning is necessary.

To deploy to Streamlit Community Cloud:

1. Push this project to your GitHub repository.
2. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Select **New app**.
4. Select the appropriate GitHub repository and branch.
5. Set the Main file path to:
   ```text
   app/streamlit_app.py
   ```
6. Click **Deploy!**.
7. Streamlit will automatically read `requirements.txt`, install dependencies, and serve the application.
8. Verify the dashboard is accessible via the generated URL.

*Note: The application uses Git-tracked pre-computed dashboard data. Docker is NOT required.*

## Data Requirements
The dashboard relies on deterministic CSV files generated by the simulation engine in `data/dashboard/`. These files are tracked in the repository and MUST exist for the dashboard to function. No live database connection is required.

## Environment Variables
The application does not require any runtime environment variables, API keys, or database credentials.

## Troubleshooting
- **Missing Data Errors**: Ensure you have not accidentally cleared the `data/dashboard/` directory. If missing, they can be regenerated by running the pipeline scripts locally (`scripts/run_data_pipeline.py`, `scripts/execute_baseline.py`, etc.) and committing them.

## Limitations
- The deployment ONLY hosts the visualization layer. It does not re-run the heavy Monte Carlo simulations or synthetic generations.
- To update the simulation, you must generate the new scenario CSVs locally, commit them to GitHub, and Streamlit Cloud will automatically update the dashboard.

## Dependency Considerations
The project explicitly separates Streamlit runtime dependencies (`requirements.txt`) from development and simulation dependencies (`requirements-dev.txt`).
- **Streamlit Community Cloud uses `requirements.txt`**, which intentionally excludes test libraries (`pytest`) and heavy C++ simulation binaries (`pyarrow>=19.0`, `scipy`). This guarantees fast and reliable cloud builds regardless of the target Python environment.
- **Local simulation/development uses `requirements-dev.txt`**, which installs the full test suite and heavy parquet/scientific processors.
