# Deployment Guide

This document describes how to deploy the AI-Process Digital Twin dashboard. 

## Prerequisites
- Python 3.13 (for local execution)
- Docker (for containerized execution)
- Git (for repository cloning)

## Local Non-Docker Execution

1. Clone the repository and navigate to the root directory.
2. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Streamlit application:
   ```bash
   streamlit run app/streamlit_app.py
   ```
5. The application will be accessible at `http://localhost:8501`.

## Docker Execution

The project includes a minimal, production-ready `Dockerfile` that packages the application and the pre-computed dashboard datasets.

### Docker Build

To build the Docker image, run the following command from the root of the repository:

```bash
docker build -t ai-process-digital-twin .
```

### Docker Run

To run the containerized application:

```bash
docker run --rm -p 8501:8501 ai-process-digital-twin
```

### Expected Application URL/Port

Once running, the dashboard will normally be accessible at:
`http://localhost:8501`

## Project Directory Requirements
The Docker image intentionally excludes raw data and heavy analytical engine files. It relies exclusively on:
- `app/`: The Streamlit dashboard pages and configuration.
- `src/`: Core logic and shared utilities (e.g., data loaders).
- `data/dashboard/`: The pre-aggregated analytical datasets.

## Data Requirements
The dashboard relies on the deterministic CSV files generated by the simulation engine in `data/dashboard/`. These files are tracked in the repository and MUST exist for the dashboard to function. No live database connection is required.

## Environment Variables
The application does not currently require any runtime environment variables, API keys, or database credentials for the visualization layer.

## Troubleshooting
- **Missing Data Errors**: Ensure you have not accidentally cleared the `data/dashboard/` directory. If missing, they can be regenerated by running the pipeline scripts locally (`scripts/run_data_pipeline.py`, `scripts/execute_baseline.py`, etc.).
- **Port Conflicts**: If port 8501 is already in use, change the port mapping in the Docker run command (e.g., `docker run --rm -p 8080:8501 ai-process-digital-twin`).

## Cloud Deployment Considerations (Streamlit Community Cloud)

**Cloud-compatible**: This repository is natively compatible with Streamlit Community Cloud.
Because the dashboard relies on tracked CSV files and a standard `requirements.txt`, no complex CI/CD or database provisioning is necessary.

To deploy to Streamlit Community Cloud (if desired in the future):
1. Connect your GitHub account to Streamlit Community Cloud.
2. Select this repository.
3. Set the Main file path to: `app/streamlit_app.py`.
4. Deploy (Streamlit will automatically read `requirements.txt` and serve the static `data/dashboard/` files).

*Note: The application has not been actually deployed to Streamlit Community Cloud as part of this module; it is merely fully prepared for it.*

## Limitations
- The deployment ONLY hosts the visualization layer. It does not re-run the heavy Monte Carlo simulations or synthetic generations.
- Because data is baked into the image, any updates to the simulation require a new Docker build.
